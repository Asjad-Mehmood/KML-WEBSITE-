# KML-WEBSITE-

Official modern landing page, interactive coordinate playground, and download portal for **Excel to KML Pro** (v3.5.1).

## 🚀 Overview
**Excel to KML Pro** is an open-source survey benchmark converter that transforms Excel/CSV coordinates into 3D Google Earth KML & KMZ with 6,864 national EPSG grids, Helmert 2D site calibration, and geotagged site photo balloons.

## 🌟 Key Highlights
- **Direct Windows Lite Installer:** Single executable (`ExcelToKMLPro-Lite-Setup.exe` • 3.2 MB) powered by Windows Edge WebView2
- **100% Offline & Private:** Zero external network egress, air-gapped security for sensitive survey benchmarks
- **Interactive Quick Playground:** Test Dubai DLTM, London OSGB36, New York NAD83, and UTM Zone 40N with live client-side `.kml` generation
- **Embedded Web App:** Single-file full converter tool (`app.html`) runnable in any browser
- **Cadastral & Civil Engineering Ready:** Column autodetect, boundary polygon surface areas (m² & ha), and known-point proving

## 🛠️ Project Structure
```
├── index.html       # Landing page with interactive tabs, specs, and FAQ
├── index.css        # Geospatial dark theme & responsive design system
├── main.js          # Interactive playground, KML generator, and scroll reveal
├── app.html         # Full standalone Excel to KML Pro web application
└── assets/          # Application icons and GIS topographic visuals
```
