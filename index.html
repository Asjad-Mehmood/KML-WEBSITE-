Built for Cadastral Surveyors, Civil Engineers & GIS Professionals

Excel to KML Pro eliminates tedious coordinate conversion errors. Designed specifically for construction site benchmarks, infrastructure surveys, boundary traverses, and drone operations.

6,864 World Grid Systems

Search by country, EPSG code, or AutoCAD drawing code (e.g. DUB-DLTM, DUB-OLD40, OSGB36). Every projection family is supported with automated 3-parameter and 7-parameter datum shift onto WGS84.

Accuracy Badges < 1m / 1-2m Tied

100% Offline & Air-Gapped

Everything runs purely on your workstation inside the Windows Edge WebView2 engine. No survey benchmarks, defense projects, or confidential site coordinates are ever transmitted to any cloud or remote server.

Privacy Standard Air-Gapped Ready

Smart Column & Raw Importer

Paste rows straight from Excel or drag-and-drop raw total station CSV files. Automatically recognises column aliases (Easting, E, X, Level, RL, Z) or reads position-based dumps with no headers.

Auto Detection 6 Headerless Orders

Helmert 2D Site Calibration

Fit a local project site grid onto national control with multi-point least-squares calibration. Calculates shift, rotation in seconds, and scale in PPM, displaying residual errors on every control point.

Verification Known-Point Prover

KMZ Geotagged Site Photos

Attach site inspection photos matching point names or coordinate tags. Automatically bundles the pictures directly inside a portable .kmz file, displaying high-res photos inside Google Earth popup balloons.

Boundary Polygons & Areas

Connect points by feature code or sequential run. Automatically closes shapes to compute exact ground perimeter length and ellipsoidal surface area in square metres (m²) and hectares (ha).

The only optional feature that touches the internet is the "Load Satellite" toggle on the map preview if you choose to turn it on.
Windows SmartScreen warns about any newly released or open-source executable that does not have an expensive commercial digital certificate ($400+/year). This is completely normal for community open-source software. Simply click "More info" and then "Run anyway". You can verify the official SHA-256 hash or review the open-source code on GitHub.
In AutoCAD Civil 3D, check your Drawing Settings under Units and Zone. For example, DUB-DLTM is Dubai Local Transverse Mercator (EPSG:3997), and DUB-OLD40 is Old Dubai on UTM Zone 40 (EPSG:27040). You can type those exact CAD codes straight into the grid search box in Excel to KML Pro, and a yellow CAD badge will confirm the match.
Yes. Raw exports from total stations (Leica, Trimble, Topcon, Sokkia) frequently contain only numbers. Excel to KML Pro automatically identifies that no headers exist and reads the columns by position. A yellow bar appears displaying the assumed column order, allowing you to select between 6 different orders (e.g., Station-Easting-Northing-Elevation or Point-Northing-Easting).
When you enter 3 or more known control benchmark coordinates, the calibration engine solves the best transformation parameters: Translation (X and Y shifts), Rotation (in seconds of arc), and Scale factor (in PPM). It highlights residual errors on each mark so you can instantly detect if a physical survey peg has been disturbed or mismeasured.
The Lite build (3.2 MB) uses the Edge WebView2 engine already pre-installed in Windows 10 and 11, resulting in a tiny download and instantaneous startup. The heavy Electron build (~62 MB) includes its own Chromium rendering engine and is only needed if running on an outdated or stripped-down Windows installation lacking WebView2.
